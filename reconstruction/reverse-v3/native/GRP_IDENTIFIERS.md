# The `grp.*` identifiers: Play Games achievements and binary literals (R47 correction)

Generated by `tools/extract_grp_identifiers.py`.

## Correction to initial sound-group assumption

This investigation originally hypothesized that `grp.*` tokens were multi-sound group keys for `MJMultiSound`.
The shipped configuration `assets/GKAchievements.plist` disproves that hypothesis:
- All 91 top-level keys in `GKAchievements.plist` are `grp.*` identifiers.
- Each key maps to a dictionary containing `{googleIdentifier: <Play Games achievement id>}`.
- `libApplication.so` carries the matching GameKit / Play Games bridge machinery (`GKAchievements`, `reportAchievement`, `achievement*`, `googleIdentifier`).

Hence, `grp.*` identifiers are achievement identifiers. Whether any of them also names a sound group is unestablished.

## Audio format string

`bird%d.wav` is a printf format string: bird audio files are loaded at runtime as `bird1.wav` .. `bird14.wav`. This explains why `bird%d.wav` does not exist verbatim on disk while the indexed variants do.

## Boundary and caveats

1. **Adjacency is not membership**: Blob order is compiler concatenation order. Co-location of audio names and achievement keys does not imply semantic relationship.
2. **Key membership**: Determining which sound files belong to which sound playback events requires caller call-site dispatch evidence, not string adjacency.
